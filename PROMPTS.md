# Copyable AI prompts

Use these with an assistant that can run commands on **your Mac**. Point it at a local clone of this repository. For physical input, report exactly which UI appeared.

## English

> Help me configure LaunchOS on this Mac. I want [plain F4 / a five-finger inward pinch on my built-in trackpad / both] to open the same grid as the LaunchOS icon in my Dock. Follow the local launchos-shortcuts README and inspect my current macOS version, LaunchOS path and hotkey, and matching keyboard services before making changes. Back up only the preferences you need to change. Preserve other HID mappings and avoid guessing device IDs. Use a reversible per-user setup. If macOS Apps opens too, distinguish recognition from activation using logs, then check the Apps and Show Desktop switches and explain any coupled change. Ask me to test the physical gesture or key and tell you whether LaunchOS, macOS Apps, both, or neither appeared. Summarize how I can undo each change.

## 简体中文

> 帮我在这台 Mac 上配置 LaunchOS。我希望用【直接按 F4／在内置触控板上五指向内捏合／两者都要】打开和点击 Dock 图标一样的界面。请按本地 launchos-shortcuts 仓库的 README 操作，先核实当前 macOS、LaunchOS 的实际路径和快捷键，以及键盘服务。只备份需要改动的偏好，保留已有的 HID 映射，不猜设备 ID。用可回退的当前用户配置。如果系统的应用列表也弹出，先用日志区分是手势没有识别，还是系统抢先打开，再检查 Apps 与「显示桌面」是否联动，并说明实际影响。最后让我亲手试一次，分别确认弹出的是 LaunchOS、系统应用列表、两个都弹出，还是没有反应，并告诉我如何撤销每项修改。
